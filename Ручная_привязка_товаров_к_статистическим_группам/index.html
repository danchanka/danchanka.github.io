Ручная привязка товаров к статистическим группам

  2. Ввести статистическую группу единично в карточке товара​

  3. Ввести статистическую группу сразу для подмножества товаров​

Заходим на форму "Товары" - в модуле "Товар" раздел "Справочники".

1. Ввести статистическую группу единично в карточке товара​

В карточке товара статистическая группа вводится в закладке Региональные параметры в поле Каноническое имя относительно типа классификатора статистических групп

2. Ввести статистическую группу для подмножества товаров​

Для включения возможности ввода одинаковой статистической группы для нескольких товаров, нужно:

  1. Выбрать в справочнике товаров тип классификатора.

  1. Возможно, воспользоваться фильтром, чтобы отобразить необходимое подмножество товаров.

  2. Включить галочку "Включить корректировку на форме".

  1. Воспользоваться Возможностями работы с объектами.
